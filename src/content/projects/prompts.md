Prompts is a curated collection of reusable AI agent prompts designed for coding agents and chat applications. It provides battle-tested prompt templates that help AI assistants produce more consistent, high-quality output across various software engineering tasks.

Whether you're building a custom coding agent or configuring an existing AI tool, these prompts can serve as a foundation for improved agent behavior and output quality.

## Features

- Ready-to-use prompt templates for common coding tasks
- Structured prompts optimized for agent-based workflows
- Covers code generation, refactoring, debugging, and documentation
